# ANBU Intelligence Glossary

**Core Division 001 · File 013 · Classification: REFERENCE**

## Purpose

Canonical definitions of ANBU-specific terms. Where a term has a common intelligence or military meaning, this file fixes the ANBU usage. For general vocabulary see `terminology_dictionary.md`.

## Scope

ANBU coinages and repurposed terms. External standard definitions (ICD 203, JP 2-0) are referenced but not reproduced; this glossary records how ANBU uses the language.

## Intelligence Objectives

- One term, one meaning, everywhere in the system.
- Prevent drift between files written at different times.
- Give reviewers a fast lookup for disputed usage.

## Core Concepts

| Term | ANBU Definition |
|---|---|
| **Assessment** | A graded judgment about a situation, built from labeled evidence. Not a fact. |
| **Analytic confidence** | Confidence in the inference drawn, distinct from source or information confidence. |
| **Collection plan** | The documented selection of sources, methods, and divisions for an engagement. |
| **Competing hypothesis** | A serious alternative explanation retained through analysis, not a strawman. |
| **Corroboration** | Independent confirmation of a claim by a source not derived from the first. |
| **Decision context** | The decision an intelligence product is meant to inform; absent context is logged as an assumption. |
| **EEI** | Essential Element of Information — the fact needed to answer an intelligence requirement. |
| **Evidence label** | One of FACT / VERIFIED / UNVERIFIED / ASSESSMENT / INFERENCE / HYPOTHESIS / SPECULATION. |
| **Falsification condition** | The observation that would overturn an assessment; required in every product. |
| **Gate** | A hard checkpoint in the interaction protocol that fails closed. |
| **Hard gate** | Steps 3 (ethics), 7 (evaluation), 10 (QA) — cannot be bypassed or compressed. |
| **Hypothesis matrix** | The ACH table mapping hypotheses to supporting and contradicting evidence. |
| **IR** | Intelligence Requirement — a decomposed sub-question serving a PIR. |
| **PIR** | Priority Intelligence Requirement — the standing question the product answers. |
| **Provenance** | The documented origin trail of an item: source, date, method, retrieval path. |
| **Source confidence** | Confidence in the origin's reliability, independent of the item's content. |
| **Information confidence** | Confidence in the specific item's accuracy, independent of the source's general reliability. |
| **UNVERIFIED** | A label, not a judgment of falsehood — the item awaits corroboration. |
| **Warning product** | A time-sensitive alert flagging a developing risk or opportunity. |

## Analytical Methodology

Glossary disputes are resolved by this file, then by `operating_principles.md`, then by escalation to the doctrine owner. Usage in products must match entries here exactly.

## Step-by-Step Workflow

1. Encounter an undefined or disputed term.
2. Check this glossary.
3. If absent, check `terminology_dictionary.md` for general vocabulary.
4. If still undefined, propose a definition; do not invent usage silently.
5. On approval, add the term here.

## Analytical Framework

**Terminology Lock**: once a term enters this glossary, its meaning is frozen for the system version. Changing a definition requires a versioned update across all files that use the term.

## Evidence Requirements

New entries require: term, definition, context of first use, and approval note.

## Confidence Assessment

- Source confidence: NOT APPLICABLE
- Information confidence: HIGH (constitutive)
- Analytical confidence: HIGH

## Common Analytical Mistakes

- Using "assessment" and "fact" interchangeably in products.
- Treating UNVERIFIED as "false" and discarding usable leads.
- Inventing local definitions inside division files.

## Ethical Considerations

Precise language is an ethical safeguard: vague terms let speculation masquerade as knowledge.

## Security Boundaries

Glossary entries describe analytical concepts only; none authorizes collection or action.

## Expected Output

Consistent terminology across all ANBU products.
