# Public Event Reconstruction

> ANBU OSINT Division 002 — Collection Tradecraft

## Purpose

Provides methodology for reconstructing public events from multiple open sources: timelines, sequences, and causal chains.

## Scope

Reconstruction of public events (incidents, crises, protests, accidents, military activities) using OSINT collection.

## Intelligence objectives

- Build chronological timelines of events
- Establish sequence and causation
- Corroborate accounts across sources
- Identify gaps and contested points

## Core concepts

- Event timeline construction
- Multi-source corroboration
- Sequence versus causation
- Contested event narratives
- Event phases: prelude, main, aftermath

## Analytical methodology

Collect all available sources: news reports, official statements, videos, images, satellite imagery, social media. Build master timeline with timestamps. Corroborate each event node across sources. Identify gaps and contradictions. Establish sequence and likely causation. Grade confidence per event node.

## Step-by-step workflow

1. Define event scope and time window
2. Collect all source types
3. Build master timeline
4. Corroborate event nodes
5. Identify gaps and contradictions
6. Produce reconstruction with confidence grading

## Data requirements

Event description; time window; geographic scope; all available source types.

## Approved public sources

- All OSINT source classes
- News reports and official statements
- Video and image evidence
- Satellite imagery
- Social media posts
- Official incident reports

## Source verification standards

Every source is evaluated for authority, proximity to the event or subject, currency, and internal consistency before its content is used analytically. Primary sources are preferred over secondary accounts. Where sources conflict, the conflict is preserved and reported rather than silently resolved. Source reliability is rated on the ANBU reliability scale and recorded in the collection log.

## Analytical framework

Event reconstruction grades each node by source count, source reliability, and temporal precision. Sequence is established by timestamped evidence. Causation is inferred only with multiple corroborating sources; otherwise flagged as association.

## Evidence requirements

Every analytical claim must be traceable to a logged collection item. Evidence requirements: (1) verbatim quotation or precise paraphrase with page/section reference; (2) source attribution including URL or archive identifier; (3) collection timestamp; (4) access method; (5) confidence grade per the ANBU scale. Claims without logged evidence are marked INSUFFICIENT and excluded from analytical products.

## Confidence assessment

HIGH: multiple independent primary sources, direct documentation, no material contradictions. MODERATE: credible sources with minor gaps or single-source primary documentation. LOW: indirect, derivative, or partially corroborated reporting. INSUFFICIENT: evidence does not support a judgment; collection gap or contested sources prevent assessment.

## Common analytical mistakes

- Building timeline from single-source accounts
- Confusing sequence with causation
- Ignoring timestamp discrepancies
- Missing that events may be ongoing

## Ethical considerations

Reconstruct events from public sources. Do not reconstruct events involving private individuals for exposure. Respect victims' privacy.

## Security boundaries

No reconstruction that enables targeting or harm. No publication of graphic content without justification.

## Expected output

Event reconstruction report with timeline, corroboration matrix, gap analysis, and confidence-graded findings.

## Quality checklist

- [ ] Timeline built
- [ ] Nodes corroborated
- [ ] Gaps documented
- [ ] Confidence graded
