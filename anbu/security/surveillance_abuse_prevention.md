# Surveillance Abuse Prevention

**Module:** ANBU OSINT — Security & Operational Protection
**Classification handling:** Apply research data classification rules to all outputs produced under this procedure. All stored artifacts must carry an analyst-assigned classification label.

## 1. Purpose
Prevent OSINT research capabilities from being used for unlawful or harmful surveillance — monitoring private individuals, tracking movements, profiling for non-legitimate purposes, or enabling stalking — while preserving legitimate intelligence research on public actors and organizations.

## 2. Scope
All research involving monitoring, tracking, or profiling of individuals or groups, including social media monitoring, geolocation analysis, behavioral profiling, and pattern-of-life assessment.

## 3. Intelligence objectives
- Distinguish legitimate intelligence monitoring (public figures, organizations, threat actors' public activity) from privacy-invading surveillance of private individuals.
- Prevent mission creep from 'monitoring public activity' to 'tracking a person.'
- Ensure monitoring is proportionate to a documented intelligence objective.
- Protect against surveillance being used for personal, political, or commercial purposes unrelated to the mandate.

## 4. Core concepts
- Subject eligibility test: is the subject a public actor acting in a public capacity, an organization, or a private individual? Private individuals get presumptive protection.
- Proportionality: monitoring intensity must match the intelligence value and the subject's public role.
- Purpose binding: monitoring authorized for one objective must not expand to general surveillance.
- Duration limits: monitoring has defined endpoints; indefinite 'just in case' watching is prohibited.

## 5. Analytical methodology
1. Define subject and verify eligibility (public actor/organization vs private individual).
2. Document intelligence objective and proportionality justification.
2.1 For private individuals: require elevated authorization and documented exceptional justification.
3. Set monitoring scope: sources, attributes, and time window.
4. Collect per scope only; review scope adherence periodically.
5. Report findings; archive or destroy monitoring data per retention.
6. Any request to expand scope triggers re-authorization.

## 6. Step-by-step workflow
1. Subject eligibility → 2. Objective + proportionality → 3. Scope definition → 4. Monitored collection → 5. Periodic scope review → 6. Reporting → 7. Retention/disposal. Scope expansion = new authorization.

## 7. Data requirements
Monitoring parameters: subject identifiers, sources monitored, attributes tracked, time window, intelligence objective, authorization reference, and review dates. No monitoring of private individuals' non-public activity under any circumstances.

## 8. Approved public sources
Public sources only. Monitoring private individuals' private communications, non-public accounts, or real-time location is outside bounds regardless of source accessibility.

## 9. Source verification standards
Monitoring quality: findings must cite specific public items with provenance; pattern claims require sufficient data density to be meaningful and are confidence-assessed per verification standards.

## 10. Analytical framework
Eligibility decision tree: public figure acting publicly? → monitor per objective. Private individual? → presumptive no; only with exceptional documented justification and elevated authorization. Organization? → monitor public activity. Family members of subjects? → protected by association.

## 11. Evidence requirements
Monitoring register: subject, eligibility basis, objective, scope, authorization, review dates, and data volume — auditable per subject.

## 12. Confidence assessment
HIGH: eligibility documented, proportionality justified, scope adhered. MODERATE: eligibility documented, scope informal. LOW: monitoring without documented objective. INSUFFICIENT: no monitoring controls.

## 13. Common analytical mistakes
Monitoring ex-partners, neighbors, or private citizens 'because we can'; pattern-of-life tracking of private individuals; expanding monitoring 'temporarily' indefinitely; using research tools for personal stalking; monitoring family members by association.

## 14. Ethical considerations
Surveillance capability is dual-use: the same techniques that monitor threat actors can destroy private lives. The ethical line is drawn by subject eligibility and purpose, not by technical capability. ANBU research serves defined intelligence objectives — never personal curiosity or private vendettas.

## 15. Security boundaries
Monitoring private individuals without exceptional authorization; indefinite surveillance; scope expansion without re-authorization; monitoring by association; using collected monitoring data for purposes outside the original objective.

## 16. Expected output
Monitoring register entries, eligibility determinations, scope reviews, and disposal records per monitored subject.

## 17. Quality checklist
- [ ] Classification label applied to every artifact
- [ ] Sources are public-only and logged with access timestamps
- [ ] Third-party tools verified against vetting checklist
- [ ] Chain-of-custody or handling record complete
- [ ] Audit entry written for every material action
- [ ] Peer or reviewer sign-off recorded where required
- [ ] Subject eligibility documented before monitoring
- [ ] Proportionality justification on file
- [ ] Scope adherence reviewed
