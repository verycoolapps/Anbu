# Government Performance Analysis

State-domain intelligence file for the ANBU analytical repository. Focus: **government performance analysis** under Indonesia's constitutional order (UUD 1945) and its democratic institutions.

## Purpose

Analyze Indonesia's government performance: ministry/agency performance, program effectiveness, and outcome achievement. This file supports analysts examining 'kinerja pemerintah' and 'LKPP' reports.

## Scope

Covers: 'LKPP' (Laporan Kinerja Pemerintah Pusat) annual reports; ministry/agency 'Laporan Kinerja'; 'RPJMN' target achievement; 'program' effectiveness; 'indikator kinerja' (performance indicators); 'evaluasi' (evaluation); 'BPK' audit findings; 'KPK' corruption cases.

## Intelligence objectives

Enable analysts to (1) assess government performance, (2) track program outcomes, (3) identify underperformers, (4) evaluate effectiveness, and (5) recommend improvements.

## Core concepts

Kinerja = performance; 'LKPP' = central government performance report; 'indikator kinerja' = performance indicator; 'evaluasi' = evaluation; 'program' = program; 'target' = target; 'capaian' = achievement; 'efektivitas' = effectiveness.

## Analytical methodology

Use LKPP reports; analyze ministry performance reports; track 'RPJMN' indicators; assess program outcomes; examine BPK audits; monitor KPK cases.

## Step-by-step workflow

Step 1: identify performance reports. Step 2: assess indicators. Step 3: evaluate outcomes. Step 4: identify underperformers. Step 5: recommend improvements.

## Data requirements

LKPP reports; ministry performance reports; 'RPJMN' indicators; program evaluation reports; BPK audit findings; KPK case data.

## Approved public sources

bappenas.go.id (LKPP); each ministry's 'kinerja' page; bpk.go.id; kpk.go.id; bps.go.id. Verify performance data via official reports.

## Source verification standards

Cross-check performance figures with LKPP; verify program outcomes with ministry reports; confirm audit findings with BPK.

## Analytical framework

Performance model: target → program → output → outcome → impact. Identify weak links.

## Evidence requirements

LKPP reports, ministry reports, indicators, evaluation reports, audit findings, corruption cases.

## Confidence assessment

HIGH for official LKPP/ministry data. MODERATE for effectiveness assessments. LOW for speculative performance claims.

## Common analytical mistakes

Confusing output with outcome; ignoring 'indikator' quality; treating 'LKPP' as perfect measure; missing regional variation; relying on ministry self-assessments.

## Ethical considerations

Performance data is public. Avoid political bias; stick to official evidence.

## Security boundaries

Do not fabricate performance data or invent 'failed programs' without official evaluation.

## Expected output

Performance memos with indicator analysis, outcome assessment, underperformer identification, and improvement recommendations. Cite LKPP/ministry data.

## Quality checklist

Reports identified? Indicators assessed? Outcomes evaluated? Underperformers found? Recommendations evidence-based?
