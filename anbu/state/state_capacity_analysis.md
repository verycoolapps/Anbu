# State Capacity Analysis

State-domain intelligence file for the ANBU analytical repository. Focus: **state capacity analysis** under Indonesia's constitutional order (UUD 1945) and its democratic institutions.

## Purpose

Analyze Indonesia's state capacity: the government's ability to implement policies, deliver services, maintain order, and respond to crises. This file supports analysts examining 'kapasitas negara' and state effectiveness.

## Scope

Covers: 'kapasitas negara' (state capacity); 'implementasi kebijakan' (policy implementation); 'pelayanan publik' (public service); 'keamanan' (security); 'respon krisis' (crisis response); 'desentralisasi' impact; 'korupsi' (corruption) impact; 'bencana' (disaster) response; 'pandemi' response.

## Intelligence objectives

Enable analysts to (1) assess state capacity, (2) identify weaknesses, (3) evaluate crisis response, (4) analyze decentralization impact, and (5) recommend improvements.

## Core concepts

Kapasitas negara = state capacity; 'implementasi' = implementation; 'pelayanan' = service; 'keamanan' = security; 'krisis' = crisis; 'bencana' = disaster; 'pandemi' = pandemic; 'desentralisasi' = decentralization; 'korupsi' = corruption.

## Analytical methodology

Use LKPP reports; analyze crisis response (COVID-19, disasters); assess service delivery; examine decentralization impact; monitor corruption cases; evaluate security effectiveness.

## Step-by-step workflow

Step 1: assess implementation capacity. Step 2: evaluate service delivery. Step 3: analyze crisis response. Step 4: assess decentralization impact. Step 5: recommend improvements.

## Data requirements

LKPP reports; crisis response reports; service delivery data; decentralization studies; corruption case data; disaster response reports.

## Approved public sources

bappenas.go.id; each ministry's 'kinerja' page; bnpb.go.id (disaster); kpk.go.id; bps.go.id. Verify capacity data via official sources.

## Source verification standards

Cross-check capacity data with LKPP; verify crisis response with official reports; confirm service data with ministry reports.

## Analytical framework

State capacity model: implementation → service → security → crisis → decentralization → corruption. Identify weak links.

## Evidence requirements

LKPP reports, crisis reports, service data, decentralization studies, corruption cases, disaster reports.

## Confidence assessment

HIGH for official LKPP/ministry data. MODERATE for capacity assessments. LOW for speculative state failure claims.

## Common analytical mistakes

Confusing capacity with resources; ignoring regional variation; treating 'desentralisasi' as always beneficial; missing informal capacity; relying on media crisis coverage.

## Ethical considerations

Capacity data is public. Avoid political bias; stick to official evidence.

## Security boundaries

Do not fabricate capacity data or invent 'failed states' without official evidence.

## Expected output

State capacity memos with implementation/service/security/crisis assessment, weakness identification, and improvement recommendations. Cite LKPP/ministry data.

## Quality checklist

Implementation assessed? Service evaluated? Crisis analyzed? Decentralization impact assessed? Recommendations evidence-based?
