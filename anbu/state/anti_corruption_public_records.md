# Anti Corruption Public Records

State-domain intelligence file for the ANBU analytical repository. Focus: **anti corruption public records** under Indonesia's constitutional order (UUD 1945) and its democratic institutions.

## Purpose

Analyze Indonesia's anti-corruption efforts using public records: KPK cases, BPK/BPKP audit findings, court decisions, and whistleblower reports. This file supports analysts examining 'pemberantasan korupsi' and 'rekam jejak' (track record).

## Scope

Covers: 'KPK' (Corruption Eradication Commission) cases; 'BPK' audit findings; 'BPKP' internal audit; 'pengadilan' (court) decisions; 'whistleblower' (pelapor); 'gratifikasi' (gratification); 'suap' (bribery); 'mark-up' (markup); 'korupsi' types; 'LP' (laporan polisi) data; 'tipikor' (corruption) statistics.

## Intelligence objectives

Enable analysts to (1) track corruption cases, (2) analyze patterns, (3) assess enforcement, (4) identify systemic issues, and (5) recommend improvements.

## Core concepts

Korupsi = corruption; 'KPK' = corruption commission; 'BPK' = audit board; 'BPKP' = internal audit; 'whistleblower' = pelapor; 'gratifikasi' = gratification; 'suap' = bribery; 'mark-up' = markup; 'tipikor' = corruption crime; 'LP' = police report.

## Analytical methodology

Use KPK case database; analyze BPK/BPKP audit findings; track court decisions; examine whistleblower reports; monitor 'tipikor' statistics; assess enforcement effectiveness.

## Step-by-step workflow

Step 1: identify cases. Step 2: analyze patterns. Step 3: assess enforcement. Step 4: identify systemic issues. Step 5: recommend improvements.

## Data requirements

KPK case database; BPK/BPKP audit reports; court decisions; whistleblower reports; 'tipikor' statistics; LP data.

## Approved public sources

kpk.go.id; bpk.go.id; bpkp.go.id; mahkamahagung.go.id; kejaksaan.go.id. Verify corruption data via official sources.

## Source verification standards

Cross-check cases with KPK; verify audit findings with BPK/BPKP; confirm court decisions with official records.

## Analytical framework

Anti-corruption model: prevention → detection → investigation → prosecution → recovery → prevention. Identify weak links.

## Evidence requirements

KPK cases, audit findings, court decisions, whistleblower reports, statistics.

## Confidence assessment

HIGH for official KPK/BPK data. MODERATE for pattern analyses. LOW for speculative corruption claims.

## Common analytical mistakes

Assuming all corruption is prosecuted; ignoring 'whistleblower' role; treating 'gratifikasi' as always corruption; missing systemic issues; relying on media corruption stories.

## Ethical considerations

Corruption data is public. Avoid defamation; stick to official findings.

## Security boundaries

Do not fabricate corruption cases or invent 'corrupt officials' without official findings.

## Expected output

Anti-corruption memos with case tracking, pattern analysis, enforcement assessment, systemic issue identification, and improvement recommendations. Cite KPK/BPK data.

## Quality checklist

Cases tracked? Patterns analyzed? Enforcement assessed? Systemic issues identified? Recommendations evidence-based?
