# State Owned Enterprise Analysis

State-domain intelligence file for the ANBU analytical repository. Focus: **state owned enterprise analysis** under Indonesia's constitutional order (UUD 1945) and its democratic institutions.

## Purpose

Analyze Indonesia's state-owned enterprises (BUMN): their role, performance, governance, and contribution to economy. This file supports analysts examining 'BUMN' and 'pengelolaan BUMN'.

## Scope

Covers: 'BUMN' (Badan Usaha Milik Negara); 'holding' structure; 'kementerian BUMN' (SOE ministry); 'BUMN' sectors (energy, finance, infrastructure, etc.); 'kinerja BUMN' (SOE performance); 'tata kelola' (governance); 'privatisasi' (privatization); 'BUMN' vs. 'BLU' (public service agency); 'BUMN' corruption cases.

## Intelligence objectives

Enable analysts to (1) map BUMN landscape, (2) assess performance, (3) evaluate governance, (4) analyze economic contribution, and (5) recommend improvements.

## Core concepts

BUMN = state-owned enterprise; 'holding' = holding company; 'tata kelola' = governance; 'privatisasi' = privatization; 'BLU' = public service agency; 'kinerja' = performance; 'BUMN' = state-owned; 'BPD' = regional development bank.

## Analytical methodology

Use Kementerian BUMN data; analyze BUMN financial reports; track 'kinerja BUMN'; assess governance; monitor privatization; examine corruption cases.

## Step-by-step workflow

Step 1: map BUMN sectors. Step 2: assess performance. Step 3: evaluate governance. Step 4: analyze contribution. Step 5: recommend improvements.

## Data requirements

Kementerian BUMN data; BUMN financial reports; 'kinerja BUMN' reports; governance assessments; privatization data; corruption cases.

## Approved public sources

bumn.go.id; kemenkeu.go.id; each BUMN's official site; kpk.go.id. Verify BUMN data via official sources.

## Source verification standards

Cross-check financial data with Kementerian BUMN; verify performance with official reports; confirm corruption cases with KPK.

## Analytical framework

BUMN model: ownership → governance → performance → contribution → reform. Identify weak links.

## Evidence requirements

BUMN data, financial reports, performance reports, governance assessments, corruption cases.

## Confidence assessment

HIGH for official Kementerian BUMN data. MODERATE for performance assessments. LOW for speculative BUMN claims.

## Common analytical mistakes

Confusing BUMN with BLU; ignoring 'holding' structure; treating 'privatisasi' as always negative; missing regional BUMN; relying on media BUMN stories.

## Ethical considerations

BUMN data is public. Avoid political bias; stick to official evidence.

## Security boundaries

Do not fabricate BUMN data or invent 'corrupt BUMN' without official findings.

## Expected output

BUMN memos with sector mapping, performance assessment, governance evaluation, contribution analysis, and improvement recommendations. Cite Kementerian BUMN data.

## Quality checklist

Sectors mapped? Performance assessed? Governance evaluated? Contribution analyzed? Recommendations evidence-based?
