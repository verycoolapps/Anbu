# Legislation Tracking

State-domain intelligence file for the ANBU analytical repository. Focus: **legislation tracking** under Indonesia's constitutional order (UUD 1945) and its democratic institutions.

## Purpose

Track Indonesia's legislative process: from bill proposal to enactment, monitoring DPR deliberations, presidential assent, and implementation. This file supports analysts examining 'proses pembentukan UU' and legislative effectiveness.

## Scope

Covers: 'Rancangan Undang-Undang' (RUU/RUU); 'DPR' deliberation process; 'Panitia Kerja' (working committees); 'pembahasan' (deliberation); 'persetujuan' (approval); 'penetapan' (enactment); 'UU' promulgation; 'implementasi' (implementation); 'evaluasi' (evaluation).

## Intelligence objectives

Enable analysts to (1) track bills through legislature, (2) identify stakeholders, (3) assess legislative effectiveness, (4) monitor implementation, and (5) predict legislative outcomes.

## Core concepts

RUU = bill; 'DPR' = parliament; 'Panitia Kerja' = working committee; 'pembahasan' = deliberation; 'persetujuan' = approval; 'penetapan' = enactment; 'UU' = law; 'implementasi' = implementation; 'evaluasi' = evaluation.

## Analytical methodology

Use DPR website for bill tracking; analyze 'RUU' documents; monitor 'Panitia Kerja' proceedings; track 'UU' promulgation; examine implementation reports; assess 'evaluasi' findings.

## Step-by-step workflow

Step 1: identify bill. Step 2: trace deliberation. Step 3: monitor approval. Step 4: track promulgation. Step 5: assess implementation.

## Data requirements

RUU documents; DPR deliberation records; 'Panitia Kerja' proceedings; 'UU' texts; implementation reports; evaluation studies.

## Approved public sources

dpr.go.id; peraturan.go.id; kemenkumham.go.id; bpk.go.id. Verify bills via official DPR/peraturan.go.id sources.

## Source verification standards

Cross-check bills with DPR records; verify 'UU' with peraturan.go.id; confirm implementation with official reports.

## Analytical framework

Legislative process model: proposal → deliberation → approval → enactment → implementation → evaluation. Identify bottlenecks.

## Evidence requirements

RUU documents, deliberation records, UU texts, implementation reports, evaluation studies.

## Confidence assessment

HIGH for official DPR/peraturan.go.id data. MODERATE for effectiveness assessments. LOW for speculative legislative predictions.

## Common analytical mistakes

Confusing RUU with UU; ignoring 'Panitia Kerja' role; treating 'persetujuan' as final (needs presidential assent); missing implementation gaps; relying on media legislative summaries.

## Ethical considerations

Legislative data is public. Avoid political bias; stick to official evidence.

## Security boundaries

Do not fabricate bills or invent 'secret legislation' without official documents.

## Expected output

Legislative memos with process tracking, stakeholder analysis, effectiveness assessment, and implementation monitoring. Cite DPR/peraturan.go.id data.

## Quality checklist

Bill identified? Deliberation traced? Approval monitored? Promulgation tracked? Implementation assessed?
